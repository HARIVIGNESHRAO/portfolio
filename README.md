# Hari Vignesh Rao - Personal Portfolio Website

A fully semantic, accessible, multi-page personal portfolio website built with **HTML5** and **CSS3**, strictly following modern web standards and **WCAG accessibility guidelines**.

---

## 📋 Project Overview

This portfolio website was developed as part of the **HTML5 Semantic Structure & Accessibility** virtual internship assignment.

### Key Features Implemented:

- **Semantic HTML5 Structure** – Proper use of `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`, etc.
- **Full WCAG Accessibility Compliance**:
  - ARIA labels and roles
  - Proper heading hierarchy
  - Keyboard navigable navigation
  - Accessible contact form with labels and `aria-required`
- **SEO Optimized** – Meta tags, descriptive titles, and semantic structure
- **Multi-Page Responsive Design**
- **Clean & Professional UI**

---

## 🛠️ Tech Stack

- **HTML5** (Semantic Tags)
- **CSS3** (Custom Styling)
- **Accessibility Standards** (WCAG 2.1)
